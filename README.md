Parkville-3D Dataset
Parkville-3D is a 3D point cloud dataset captured in urban environments, specifically designed to support research in semantic segmentation and instance segmentation.

📥 Dataset Download
The dataset is officially hosted on Zenodo. You can access and download the data via the following link:
[Download on Zenodo](https://zenodo.org/records/18813190)
